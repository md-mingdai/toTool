# toTool

一款面向 Android 的本地工具箱：60 个日常、文本、计算、设备、图片与媒体工具，加上格式转换、条码处理、方程求解、函数绘图和隔空闪传。界面采用 Miuix（HyperOS 风格），所有处理都在本机完成，不收集数据、不需要账号。

## 功能

### 隔空闪传

- 手机作为局域网文件服务器，自动选择可用端口，电脑浏览器或扫码进入文件管理器。
- 浏览手机存储与照片、视频、应用等分类，支持搜索、上传下载、文件夹打包下载、分页、排序、批量操作和远程删除；上传前可在传输队列中确认文件。图片可直接查看，视频和音频可直接播放，1 MiB 以内的文本和源代码可直接预览，Markdown 会渲染显示。
- 配对码配合 token 保持会话；配对码可固定，也可在每次配对成功后自动轮换。网页也可发起交互式配对：网页显示一个随机两位数，手机端从三个不同的两位数中选出相同的一项后才完成配对，并可暂时拉黑某台设备。
- 可选端到端加密：文件内容使用 AES-256-GCM，密钥不随文件请求传输。
- 网页支持 PJAX 导航、任务进度和断连提示，最近传输里可以删除已上传到手机的文件；手机端分为「连接 / 已接收 / 剪贴板」，已接收文件可删除，剪贴板双向同步。

### 条码处理

- 生成与扫描：QR、汉信码、Data Matrix、PDF 417、Code 49，以及 Code 128 / 39 / 93、ITF、EAN-13 / EAN-8、UPC-A、Codabar。
- 相机实时取景或相册图片识别，支持多码跟踪和横放 / 竖放一维码。
- 汉信码与 Code 49 的编解码在项目内实现，生成时会做编码 → 解码自检。

### 方程求解与函数绘图

- 支持一元一次、二次及可化为多项式的分式方程，给出精确根、定义域和增根提示；无法精确求解时回退数值扫描。
- 方程输入器采用 Desmos 风格；函数绘图支持多曲线、缩放平移、点按取值和渐近线断开。

### 格式转换

- 基于内置 FFmpeg，支持图片、视频、音频之间的跨媒体转换：图片可按时长生成视频（可另选配乐），视频可提取音频或指定帧图片，音频可配封面、波形、纯色或自定义画面生成视频。
- 源文件类型由文件头和扩展名自动识别，不需要手动选择；目标格式按「图片 / 视频 / 音频」分组，同源格式自动置灰。
- 动图支持 GIF / APNG：可以转为视频或 GIF，视频也可导出为动图 GIF；动图转静态图片时取第一帧。
- 图片转 GIF 会进入「GIF 合成」：原图固定在列表顶端，可继续追加图片，设置每张静态图片的停留帧数，GIF 总帧数自动按列表求和；追加的 GIF / APNG 会按自身帧展开，停留帧数不适用。
- 图片格式使用系统编解码器；视频/音频支持 MP4 / MKV / MOV / AVI / WebM、MP3 / WAV / AAC / M4A / FLAC / OGG 等，实际选项按内置编码器探测结果过滤。
- 视频转图片支持帧号与预览。
- 音频转视频使用内嵌封面时，按封面原始宽高比自适应视频尺寸，不再固定裁成 16:9。
- 音频转视频的波形画面可配置样式（填充 / 线条 / 点 / 峰对峰）、波形颜色和背景色，背景预设包含绿幕，便于后期抠像。
- 音频与图片互转在「图片唱片」工具中：把音频以 Base64 编码进 PNG 像素，或从 PNG 还原音频（娱乐，不是加密）；还原后可以先试听再导出。
- 原始 FFmpeg 命令模式，支持输入占位符、实时日志和进度。
- 输出保存到「下载/toTool」，文件较多时自动打包；图片保存到「相册/toTool」。

### 媒体工具

- 视频倒放、音频倒放：同时反转画面与音轨；音频默认跟随源文件格式，也可指定 M4A 或 MP3。
- 画中画：把一段视频缩放到另一段视频的左上 / 右上 / 左下 / 右下角，使用主视频音轨。
- 字幕烧录：解析 SRT / ASS，或从 MKV 等容器读取第一条内嵌字幕轨，逐条渲染后叠加到画面并输出 MP4。
- 视频裁剪：拖动起始与结束位置，只裁长度，保留原画面。
- 视频添加水印：支持文字或图片水印，可选四角位置和透明度。
- 视频压缩：480p / 540p / 720p / 1080p 四种高度预设，可调 CRF 与 ultrafast / fast / medium / slow 编码预设。
- 视频旋转与变速：顺时针 90° / 180° / 270°，以及 0.5×–2× 同步变速。
- 所有视频工具都会显示选中视频的预览帧；裁剪按起始位置刷新，画中画/水印/旋转/字幕会直接合成效果预览。
- 音频工具显示内嵌封面，并支持试听原音频。
- 全部使用内置 FFmpeg；字幕和水印由 Android Canvas 渲染成透明覆盖层，不依赖 libass / drawtext。

## 大致实现

- 单 APK，Jetpack Compose + Miuix，统一管理页面转场、方向锁和沉浸式系统栏；高级权限可由设置页在 Shizuku 与 Root 间切换。
- 条码使用 ZXing、CameraX 和项目内的汉信码 / Code 49 编解码器；实时扫描分为快慢路径并跟踪多个码框。
- 方程求解使用任意精度有理数、多项式和根式运算；无法精确求解时转为数值扫描。
- FFmpeg 以 `libffmpeg.so` 形式按 CPU 架构打包，由 CI 从源码交叉编译；启用 GPL 构建，带 x264（H.264）与 libvpx（VP8/VP9），并保留 mpeg4 兜底。媒体工具的字幕、水印先由 Canvas 渲染成透明 PNG，再交给 FFmpeg overlay，避免依赖 libass / drawtext。
- 隔空闪传网页位于 `web/`，使用 Vite + React + TypeScript；CI 只把 `web/dist` 放进 APK。
- 手机端内嵌 Ktor 服务器，提供静态页面和同源 API；文件通过「所有文件访问权限」读写，上传默认保存到 `Download/toTool/FlashDrop/`。
- 弱网助手通过 VPN 把所选应用导向本地 HTTP 代理，按 KB/s 和附加延迟限速，并支持目标主机过滤与悬浮窗监控。
- 配对码由手机端校验并限速；加密密钥由配对码和随机 salt 派生。网页优先使用 WebSocket 长连接，不支持或断开时回退到 HTTP 探活。

## 隐私与权限

所有功能都在本机完成，不包含统计、广告或账号系统。隔空闪传只在同一局域网内提供网页服务，文件不经过云端。

| 权限 | 用途 |
| --- | --- |
| `CAMERA` / `RECORD_AUDIO` | 条码扫描、手电筒、分贝仪 |
| `VIBRATE` | 振动工具与触感反馈 |
| `INTERNET` / `ACCESS_NETWORK_STATE` | 网络信息工具；隔空闪传局域网服务 |
| `QUERY_ALL_PACKAGES` | 提取 APK、展示已安装应用 |
| `REQUEST_INSTALL_PACKAGES` | 安装 APKS / XAPK / APKM |
| 媒体读取权限 | 格式转换与媒体工具读取用户选择的媒体 |
| `MANAGE_EXTERNAL_STORAGE` | 读取真实壁纸；隔空闪传浏览 / 上传 / 下载手机文件 |
| `SYSTEM_ALERT_WINDOW` | 弱网助手悬浮窗 |
| `POST_NOTIFICATIONS` / 前台服务 | 弱网助手运行状态通知 |
| 通知使用权 | 通知管理：隐藏、提取和导出通知（在系统设置中手动授权） |

> 隔空闪传是局域网 HTTP 服务，配对码和接口请求不经过 TLS；请只在可信 Wi-Fi 下使用。
