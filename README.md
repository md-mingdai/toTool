# toTool

一款面向 Android 的本地工具箱：78 个日常、文本、计算、设备、图片、媒体与高级工具，加上格式转换、条码处理、方程求解、函数绘图和隔空闪传。界面采用 Miuix（HyperOS 风格），所有处理都在本机完成，不收集数据、不需要账号。

## 功能

### 隔空闪传

- 手机作为局域网文件服务器，自动选择可用端口，电脑浏览器或扫码进入文件管理器。
- 浏览手机存储与照片、视频、应用等分类，支持搜索、上传下载、文件夹打包下载、分页、排序、批量操作和远程删除；上传前可在传输队列中确认文件。图片可直接查看，视频和音频可直接播放，1 MiB 以内的文本和源代码可直接预览，Markdown 会渲染显示。
- 配对码配合 token 保持会话；配对码可固定，也可在每次配对成功后自动轮换。网页也可发起交互式配对：网页显示一个随机两位数，手机端从三个不同的两位数中选出相同的一项后才完成配对，选错会直接取消本次请求，并可暂时拉黑某台设备。
- 可选端到端加密：文件内容使用 AES-256-GCM，密钥不随文件请求传输。
- 网页支持 PJAX 导航、任务进度和断连提示，最近传输里可以删除已上传到手机的文件；手机端分为「连接 / 已接收 / 剪贴板」，已接收文件可删除，剪贴板双向同步。

### 条码处理

- 生成与扫描：QR、汉信码、Data Matrix、PDF 417、Code 49，以及 Code 128 / 39 / 93、ITF、EAN-13 / EAN-8、UPC-A、Codabar。
- 相机实时取景或相册图片识别，支持多码跟踪和横放 / 竖放一维码。
- 汉信码与 Code 49 的编解码在项目内实现，生成时会做编码 → 解码自检。

### 方程求解与函数绘图

- 支持一元一次、二次及可化为多项式的分式方程，给出精确根、定义域和增根提示；无法精确求解时回退数值扫描。
- 方程输入器支持分式与根式的结构化输入；函数绘图支持多曲线、缩放平移、点按取值和渐近线断开。
- 方程和函数表达式在输入框内直接排版渲染，输入框内显示闪烁光标，支持粘贴 LaTeX 源码；配合计算器式数学键盘（函数键、角度快捷值、数字与运算符、扩展函数页）。公式字体随 APK 打包，离线可用；另有独立的「LaTeX 渲染」工具。

### 格式转换

- 基于内置 FFmpeg，支持图片、视频、音频之间的跨媒体转换：图片可按时长生成视频（可另选配乐），视频可提取音频或指定帧图片，音频可配封面、波形、纯色或自定义画面生成视频。
- 源文件类型由文件头和扩展名自动识别，不需要手动选择；目标格式按「图片 / 视频 / 音频」分组，同源格式自动置灰。
- 动图支持 GIF / APNG：可以转为视频或 GIF，视频也可导出为动图 GIF；动图转静态图片时取第一帧。
- 图片转 GIF 会进入「GIF 合成」：原图固定在列表顶端，可继续追加图片，设置每张静态图片的停留帧数，GIF 总帧数自动按列表求和；追加的 GIF / APNG 会按自身帧展开，停留帧数不适用。
- 图片格式使用系统编解码器，并支持 ICO 源/目标（多尺寸 16–256）与 SVG 源：SVG 需要指定输出宽高，由 AndroidSVG 渲染成位图后再转换；SVG 不能作为目标格式，在格式选择框中会置灰。
- 视频/音频支持 MP4 / MKV / MOV / AVI / WebM、MP3 / WAV / AAC / M4A / FLAC / OGG 等，实际选项按内置编码器探测结果过滤。
- 视频转图片支持帧号输入、预览，也可以拖动进度条选择帧。
- 音频转视频使用内嵌封面时，按封面原始宽高比自适应视频尺寸，不再固定裁成 16:9。
- 音频转视频的波形画面可配置样式（填充 / 线条 / 点 / 峰对峰）、波形颜色和背景色，背景预设包含绿幕，便于后期抠像。
- 音频与图片互转在「图片唱片」工具中：把音频以 Base64 编码进 PNG 像素，或从 PNG 还原音频（娱乐，不是加密）；还原后可以先试听再导出。
- 原始 FFmpeg 命令模式，支持输入占位符、实时日志和进度。
- 输出保存到「下载/toTool」，文件较多时自动打包；图片保存到「相册/toTool」。

### 图片工具

- 纯色图制作:自定义宽高与 HSV 颜色,生成 PNG 并保存到相册。
- 九宫格切图:预览 3×3 分割线,可先居中裁切为 1:1,一次保存九张切片。
- 图片文字化:按字符格取色和亮度,用不同颜色、不同密度的 ASCII 字符重新组成图片;可指定字符密度(密度越高生成分辨率越大),字符集仅限标准 ASCII,背景可自定义或取原图主色;渲染优先使用内置 Onest 字体,不可用时回退系统默认;可把字符画导出为纯文本(不包含颜色和背景)。
- 图片转素描:灰度反相、模糊和颜色减淡的铅笔素描效果,可调强度。
- 图片取色:点击图片读取像素颜色,自动提取主色并复制 HEX。
- 图片与 Base64 互转:图片编码为带 MIME 标记的 data URI,输出框限高,可复制或导出为文本;也支持把 Base64 / data URI 解码预览并保存到相册。

### 系统工具

- 电量伪装:通过 Shizuku / Root 修改系统上报的电量、充电状态,可一键恢复。
- DPI 修改:读取当前密度并应用自定义 DPI,支持恢复默认。
- 高级重启:设备重启、快速重启(软重启,仅 Root)、重启用户界面(仅 Root)、设备关机、重启至 Recovery、重启至 fastboot(bootloader)、重启至 fastbootd、重启至安全模式(仅 Root)。
- 系统界面调节工具:点击工具卡片直接拉起 SystemUI DemoMode,没有工具页面。
- 全局方向调节:通过不可见悬浮窗锁定系统方向,工具页顶端只有一个胶囊开关用于启用/停用,需要悬浮窗权限。
- 执行 Shell 指令:通过 Shizuku / Root 执行命令或 `.sh` 脚本;导入的脚本会保存到脚本库并在重启后保留,运行状态记录在运行历史里。

### 模拟来电

- 通过系统 Telecom 注册通话账户,在真实电话/拨号界面显示来电;可设置来电人姓名、号码、隐藏号码与响铃超时。
- 支持立即来电或按秒定时;定时使用系统精确闹钟。接听后可选循环播放本地音频,未选择时用系统 TTS 朗读默认语句。
- 需要电话状态与号码权限;首次使用需在系统通话账户设置中启用「模拟来电」;Android 12+ 的定时功能需要精确闹钟权限,定时状态会在重启或应用更新后恢复。仅供个人设备上的测试、演示或脱身场景,请勿用于欺骗、骚扰或冒充他人。

### 数据库管理

- 远程 MySQL / MariaDB：填写主机、端口、用户名、密码和可选数据库，支持 SSL；连接后可切换数据库、浏览表和视图、分页查看数据，并通过 SQL 编辑器执行查询和写操作。
- SQLite：打开 `.db` / `.sqlite` / `.sqlite3` 单文件数据库，或新建数据库；可在手机上浏览表、执行 SQL。修改写入应用私有工作副本，点「保存」后再覆盖回原文件，也可以导出副本。
- 远程密码只在本次会话内使用，不持久化；SQL 结果最多预览 200 行，表数据每页 50 行。执行 DROP / TRUNCATE 前会二次确认。

### 应用管理

- 扫描已安装应用并分为用户应用 / 系统应用两个标签，支持按应用名或包名搜索。
- 点按应用打开居中的详情弹窗，显示包名、安装路径、TargetSDK 和 MinSDK。
- 支持跳转系统应用详情 / 应用商店、清除数据（可仅当前用户）、卸载（可保留数据或仅当前用户）、冻结 / 解冻（限制使用 / suspend / 完全隐藏）、四种互斥的 Dex2oat 模式，以及查看 Activity 列表。
- 提取安装包合并到应用详情中：普通应用导出 APK，带拆分包的 AAB 应用导出 .apks。修改类操作需要 Shizuku 或 Root。

### 后台任务

- 隔空闪传、弱网助手、全局方向、格式转换、FFmpeg 命令和媒体工具在执行后不会随页面关闭而停止。
- 有需要保活的任务时,toTool 以前台服务运行。
- 首页右侧提供可收纳任务抽屉,可查看运行中的工具、进度并停止任务;前台服务通知里也可一键「结束全部」。

### 媒体工具

- 视频倒放、音频倒放：同时反转画面与音轨；音频默认跟随源文件格式，也可指定 M4A 或 MP3。
- 画中画：把一段视频缩放到另一段视频的左上 / 右上 / 左下 / 右下角，使用主视频音轨。
- 字幕烧录：解析 SRT / ASS，或从 MKV 等容器读取第一条内嵌字幕轨，逐条渲染后叠加到画面并输出 MP4。
- 视频裁剪：拖动起始与结束位置，只裁长度，保留原画面。
- 视频添加水印：支持文字或图片水印，可选四角位置和透明度。
- 视频压缩：480p / 540p / 720p / 1080p 四种高度预设，可调 CRF 与 ultrafast / fast / medium / slow 编码预设。
- 视频旋转与变速：顺时针 90° / 180° / 270°，以及 0.5×–2× 同步变速。
- 所有视频工具都会显示选中视频的预览帧；裁剪按起始位置刷新，画中画/水印/旋转/字幕会直接合成效果预览。
- 音频工具显示内嵌封面，并支持试听原音频。
- 全部使用内置 FFmpeg；字幕和水印由 Android Canvas 渲染成透明覆盖层，不依赖 libass / drawtext。

### 视频链接解析

- 支持抖音、小红书、快手、微博、AcFun、哔哩哔哩、Pixiv 的分享链接/分享文案识别与解析。
- 展示作品标题、作者、文案、封面和视频/图集直链,可复制、浏览器打开或用系统下载器下载;下载会带上平台要求的 Referer/Cookie。
- 图集图片会在每条媒体卡片中逐张加载缩略预览;视频媒体优先在卡片内用 WebView 自动播放直链,不支持或鉴权失败时回退到封面。输入框右侧可一键清空,未解析时表单在页面内垂直居中。
- 小红书需要登录 Cookie;哔哩哔哩和 Pixiv 可选填 Cookie 以提升清晰度或解锁受限作品。
- 解析逻辑按各平台公开页面与接口协议独立实现；遇到登录态或风控限制时会给出针对性提示。

### Markdown 渲染

- 支持 CommonMark / GFM 常用语法：标题、列表、引用、表格、任务列表、删除线、自动链接、图片和围栏代码块；行内 / 块级 LaTeX 公式用内置 KaTeX 渲染。
- 内置 GitHub、VitePress 文档和 Sky 三种排版，可切换亮色 / 深色主题；Sky 样式使用高亮标题、圆角表格和衬线正文。
- 实时预览整篇 Markdown，可自定义导出图片宽度并保存为一张长图到相册「Pictures/toTool」，也可以导出为单个 HTML 文件（样式、字体和脚本全部内联，源码压缩为一行，可选择保留远程图片原始 URL 或下载后转成 Base64）；输入不设长度上限，超长文档导出时只提示内存/耗时风险，不预先阻止。
- 原始 HTML 会按普通文本显示，预览和导出使用本地打包的解析器与高亮脚本；远程图片需要联网加载。
- 导出图片和单文件 HTML 时都会显示当前任务、阶段详情和进度；远程图片可在 HTML 中保留 URL 或下载为 Base64。

## 大致实现

- 单 APK，Jetpack Compose + Miuix，统一管理页面转场、方向锁和沉浸式系统栏；高级权限可由设置页在 Shizuku 与 Root 间切换。
- 条码使用 ZXing、CameraX 和项目内的汉信码 / Code 49 编解码器；实时扫描分为快慢路径并跟踪多个码框。
- 方程求解使用任意精度有理数、多项式和根式运算；无法精确求解时转为数值扫描。
- FFmpeg 以 `libffmpeg.so` 形式按 CPU 架构打包，由 CI 从源码交叉编译；启用 GPL 构建，带 x264（H.264）与 libvpx（VP8/VP9），并保留 mpeg4 兜底。媒体工具的字幕、水印先由 Canvas 渲染成透明 PNG，再交给 FFmpeg overlay，避免依赖 libass / drawtext。
- 隔空闪传网页位于 `web/`，使用 Vite + React + TypeScript；CI 只把 `web/dist` 放进 APK。
- 手机端内嵌 Ktor 服务器，提供静态页面和同源 API；文件通过「所有文件访问权限」读写，上传默认保存到 `Download/toTool/FlashDrop/`。
- 弱网助手用 VpnService 的 TUN 接管所选应用的 TCP 与 UDP 流量，交给本地 SOCKS5 转发层（hev-socks5-tunnel）直连目标，可按 KB/s、附加延迟、抖动与丢包限速，支持 UDP 会话、DNS、IPv4 / IPv6、目标主机过滤与悬浮窗监控；UDP 丢包直接丢弃数据报，TCP 丢包以重传停顿模拟，避免破坏字节流；暂停会关闭 VPN/TUN 切回直连网络，前台服务、通知和悬浮球保留，继续限制时重新建立 VPN，停止服务才结束任务。
- 密码生成使用拒绝采样保证字符池内等概率；可选采样传感器、麦克风、摄像头，将采样数据与系统随机种子混合。绘制笔迹则作为唯一种子，同一笔迹与相同设置会复现同一密码；所有原始采样都不落盘。
- 格式转换中的 SVG 由 AndroidSVG 渲染，ICO 由项目内的轻量编解码器读写（支持 PNG 条目和常见 BI_RGB 位深）；SVG 分辨率在转换前由用户指定。
- 方程与函数输入框本身就是渲染后的公式，可直接粘贴 LaTeX；独立的 LaTeX 渲染工具支持实时查看任意数学公式。KaTeX 字体作为资源模块打进 APK，不依赖网络或 WebView。
- 倒数日使用 SharedPreferences 保存，主屏幕组件由 AppWidgetProvider + RemoteViews 绘制；日期变化、时区变化和定时刷新都会更新最近一条。
- 数据库管理使用轻量的 MariaDB Connector/J（约 0.6 MB）连接 MySQL / MariaDB；SQLite 直接使用 Android 自带的 SQLiteDatabase，不额外引入 ORM 或数据库引擎，以控制 APK 体积。
- Unicode 编解码支持 UTF-16 `\uXXXX`（含代理对）、码点 `U+XXXX`、`\u{...}`、`\UXXXXXXXX` 与 HTML 数字实体；解码自动识别这些写法、处理 `\\` 转义并保留其余原文，默认编码会保护原文里类似转义的字样，保证往返一致。
- Markdown 渲染使用 commonmark-java 解析 CommonMark / GFM，样式由内置 CSS 控制，代码高亮使用本地 highlight.js，数学公式使用本地 KaTeX；导出时在离屏 WebView 中按整篇内容高度绘制为 PNG，宽度可自定义，单文件 HTML 则把 KaTeX 字体等资源转成内联 data URI，并可选择把远程图片也下载后内嵌。
- 应用管理通过 PackageManager 枚举用户与系统应用；冻结、卸载、清除数据和 Dex2oat 等修改通过 Shizuku / Root 执行，提取安装包复用系统下载目录（带拆分包的 AAB 应用合并为 .apks）。
- 配对码由手机端校验并限速；加密密钥由配对码和随机 salt 派生。网页优先使用 WebSocket 长连接，不支持或断开时回退到 HTTP 探活。

## 隐私与权限

所有功能都在本机完成，不包含统计、广告或账号系统。隔空闪传只在同一局域网内提供网页服务，文件不经过云端。密码熵源的传感器、麦克风、摄像头采样和绘制笔迹只在该次生成时使用，原始数据不保存。数据库管理会从本机直接连接用户填写的 MySQL / MariaDB 服务器，凭据不经过第三方，远程密码不会持久化。

| 权限 | 用途 |
| --- | --- |
| `CAMERA` / `RECORD_AUDIO` | 条码扫描、手电筒、分贝仪、密码熵源采样 |
| `VIBRATE` | 振动工具与触感反馈 |
| `INTERNET` / `ACCESS_NETWORK_STATE` | 网络信息工具；隔空闪传局域网服务 |
| `QUERY_ALL_PACKAGES` | 应用管理、提取安装包、展示已安装应用 |
| `REQUEST_INSTALL_PACKAGES` | 安装 APKS / XAPK / APKM |
| 媒体读取权限 | 格式转换与媒体工具读取用户选择的媒体 |
| `MANAGE_EXTERNAL_STORAGE` | 读取真实壁纸；隔空闪传浏览 / 上传 / 下载手机文件 |
