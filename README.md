# toTool

一款面向 Android 的本地工具箱：46 个日常、文本、计算、设备与图片工具，加上格式转换、条码处理、方程求解、函数绘图和隔空闪传。界面采用 Miuix（HyperOS 风格），所有处理都在本机完成，不收集数据、不需要账号。

## 功能

### 隔空闪传

- 手机作为局域网文件服务器，从 `2233` 到 `2333` 自动选择第一个可用端口，电脑浏览器或扫码直接进入文件管理器。
- 浏览手机存储、照片、视频、音频、文档、压缩包、安装包、已安装应用、下载、剪贴板和最近传输；支持文件夹、搜索、详情、上传、下载、应用 APK 下载与剪贴板复制。文件列表按真实总数分页，每页 250 项，底部提供页码翻页。下载文件夹时先在手机上打包为 `.zip` 再传输。上传保存到 `Download/toTool/FlashDrop/`。
- 网页使用 History API / PJAX 导航，分类、文件夹路径和搜索结果都会反映到地址栏，支持浏览器前进/后退；默认进入手机存储。
- 首次访问需要输入手机端显示的 6 位配对码，配对后通过 token 保持会话。
- 配对码默认每次成功配对后自动轮换，也可以设置固定的自定义 6 位配对码。
- 可选端到端加密：文件内容使用由配对码和随机 salt 经 PBKDF2 派生的 AES-256-GCM 密钥加密，按 1 MiB 分块流式处理，密钥不随文件请求传输。
- 服务只在隔空闪传页面打开期间运行；进入工具页会先申请「所有文件访问权限」。后端断开时网页顶部显示横幅提示。
- 手机端分为「连接 / 已接收 / 剪贴板」三页：连接页管理服务与配对，已接收页查看电脑上传的文件，剪贴板页像 IM 一样双向收发文字。
- 网页任务列表会显示正在传输、已完成、已取消和失败的任务，标出上传、加密、下载、解密阶段与实时速度，支持取消与删除，顶部还有全局进度条。
- 网页文件列表支持复选、全选、批量下载和远程删除手机文件（删除前二次确认）；文件预览禁止鼠标拖拽。

### 条码处理

- 生成与扫描：QR、汉信码、Data Matrix、PDF 417、Code 49，以及 Code 128 / 39 / 93、ITF、EAN-13 / EAN-8、UPC-A、Codabar。
- 扫描支持 CameraX 实时取景和相册图片；相机画面使用智能镜头风格的透视跟随框，贴着码倾斜、移动和缩放，框正中显示「查看二维码 / 查看条形码」胶囊，多码同时跟随时也保持平滑。一维码支持横放和竖放，竖放时会显式旋转两个方向识别并映射回原画面。
- 汉信码与 Code 49 的矩阵布局、纠错和载荷解析在项目内实现，生成时会做编码 → 解码自检。

### 方程求解与函数绘图

- 一元一次、二次及可化为多项式的分式方程支持精确形式：分数、最简根号、复根、判别式、定义域和增根。
- 非多项式或高次方程自动回退数值扫描。
- 方程输入器采用 Desmos 风格：大号公式区、函数快捷键和数学键盘。
- 函数绘图支持多条曲线、缩放平移、点按取值、渐近线断开和网格自适应。

### 格式转换

基于内置 FFmpeg：

- 图片、音频、视频格式互转，常用预设与自定义参数。
- 原始 FFmpeg 命令模式，支持 `{in1}`…`{in8}`、实时日志、进度和停止。
- 输出保存到「下载/toTool」，文件较多时自动打包。

## 大致实现

- 单 APK，Jetpack Compose + Miuix；页面转场、方向锁和沉浸式系统栏由统一路由管理。
- 条码生成使用 ZXing，汉信码与 Code 49 由项目内的编码器 / 采样解码器处理；摄像头使用 CameraX。实时识别只取 YUV 的 Y 平面并复用灰度缓冲，分析线程执行位移估计、快路径解码和码框定位；汉信码、Code 49、反色与竖放一维码在独立慢路径线程带截止时间执行。跟踪器把位置和形状分开滤波，界面按速度外推到当前时刻，避免框滞后或抖动。
- 方程求解使用任意精度有理数、多项式和根式运算；无法精确求解时转为数值扫描。
- FFmpeg 以 `libffmpeg.so` 形式按 CPU 架构打包，由 CI 从源码交叉编译。
- 隔空闪传网页位于 `web/`，使用 Vite + React + TypeScript；CI 只把 `web/dist` 构建产物放进 APK 的 `assets/flashdrop/`。
- 手机端内嵌 Ktor CIO：提供静态页面和同源 `/api`，按端口范围递增选端口；文件通过「所有文件访问权限」读写，应用来自 PackageManager，剪贴板走系统 ClipboardManager。上传默认保存到 `Download/toTool/FlashDrop/`。
- 配对码由手机端校验并限速；自动模式下，成功配对后立即轮换。加密密钥由配对码 + 随机 salt 经 PBKDF2 派生，文件内容按 1 MiB 分块用 AES-256-GCM 加密；网页端使用纯 JS 的 noble 实现，HTTP 局域网下也能工作。
- 网页刷新时通过 `/api/session` 验证 token；网页与手机端优先建立 WebSocket 长连接（心跳保活），不支持或断开时回退到 `/api/info` 探活，两种方式都失败时显示连接横幅。

## 隐私与权限

所有功能都在本机完成，不包含统计、广告或账号系统。隔空闪传只在同一局域网内提供网页服务，文件不经过云端。

| 权限 | 用途 |
| --- | --- |
| `CAMERA` / `RECORD_AUDIO` | 条码扫描、手电筒、分贝仪 |
| `VIBRATE` | 振动工具与触感反馈 |
| `INTERNET` / `ACCESS_NETWORK_STATE` | 网络信息工具；隔空闪传局域网服务 |
| `QUERY_ALL_PACKAGES` | 提取 APK、展示已安装应用 |
| `REQUEST_INSTALL_PACKAGES` | 安装 APKS / XAPK / APKM |
| 媒体读取权限 | 格式转换读取用户选择的媒体 |
| `MANAGE_EXTERNAL_STORAGE` | 读取真实壁纸；隔空闪传浏览 / 上传 / 下载手机文件 |

> 隔空闪传是局域网 HTTP 服务，配对码和接口请求不经过 TLS；请只在可信 Wi-Fi 下使用。
